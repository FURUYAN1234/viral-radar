# v1.4.3 — Stop AI communication / AI通信の強制切断

## Changes / 更新内容

- Added a prominent red stop button, enabled only during active AI work including reasoning wait and response reception. / 思考待ち・応答受信中を含むAI処理中だけ押せる、目立つ赤い停止ボタンを追加しました。
- Propagates cancellation to provider requests and stops fallback, automatic correction and late output adoption. Explicit new runs retain inputs and accepted results. / プロバイダー通信へ中断を伝え、モデル切替・自動修正・遅延結果の採用を止めます。入力と採用済みの結果を保持して再実行できます。
- Updated the operation/API PDFs and README. API billing already incurred is separate. / 操作・API設定PDFとREADMEを更新しました。既に発生したAPI利用料金は別です。

- Keep emergency stop at the upper right in normal, thinking, stopped and scrolled views, with reserved header space. Wrap long model descriptions/prices, including GPT-6 Luna. / 通常・思考中・停止後・スクロール時も緊急停止を右上に保ち、ヘッダー用の余白を確保します。GPT-6 Lunaを含む長いモデル説明・料金を折り返します。

- Hide the stop control and its reserved band on the initial API gate. Workspace controls use top 20px/right 12px, stay reachable above overlays, and wrap long model metadata. / 初期API設定画面では停止ボタンと専用余白を非表示にし、作業画面では上20px・右12pxに固定。処理画面より前で押せ、長いモデル情報も折り返します。
