# Monogatari Buzz Maker v1.4.7 / リリース v1.4.7

## Changes / 更新内容

- Use MCP to retrieve public Web and RSS evidence and create a report and proposals. The selected prompt can be passed to Story Maker. / MCPで公開Web・RSSの根拠を集め、レポートと企画を作れます。採用した企画のプロンプトをStory Makerへ渡せます。
- Added a verified local MCP connection with a single stop control at the top of the app. / ローカルMCP接続に対応し、接続中の停止操作を画面上部の一つのボタンにまとめました。
- The app offers its production skill, MCP setup guide, operation manual, and API setup manual in the upper toolbar. / 画面上部から制作スキル、MCP導入ガイド、操作マニュアル、API設定マニュアルを開けます。
- Launch-MCP.cmd starts and stops the service and checks for app updates on Windows. / Windows用のLaunch-MCP.cmdからサーバーの起動・停止と更新の確認ができます。
- Synchronized the bundled OpenAI fallback configuration with Super FURU AI 4-koma System v8.0.9. / 同梱のOpenAIフォールバック設定をSuper FURU AI 4-koma System v8.0.9に同期しました。
