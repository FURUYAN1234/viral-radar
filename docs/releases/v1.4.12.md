# Monogatari Buzz Maker v1.4.12 / 物語バズメーカー v1.4.12

- JSON and DOCX save dialogs initially suggest the Downloads folder. You can still choose the destination and file name. / JSONとDOCXの保存時に、最初に「ダウンロード」フォルダーを表示します。フォルダーとファイル名は変更できます。
- On platforms without a supported file picker, the app uses the available save method. It ends the operation on cancellation or access denial and displays write failures. / 保存ダイアログに非対応の環境では、利用できる保存方法に切り替えます。取消やアクセス拒否で操作を終了し、書き込みに失敗した場合はエラーを表示します。
