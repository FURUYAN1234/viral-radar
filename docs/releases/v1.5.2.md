# Monogatari Buzz Maker v1.5.2 / 物語バズメーカー v1.5.2

- Release numbering carries at 9. The changes first published under v1.4.12 are available as v1.5.2. / 版番号は末尾の9で繰り上げます。v1.4.12の表記で公開した変更はv1.5.2に収録しています。
- JSON and DOCX use the browser's download settings. A separate choice lets you select the destination and file name. / JSONとDOCXの通常保存はブラウザーのダウンロード設定に従います。「保存先を選ぶ」でフォルダーとファイル名を指定できます。
- Destination selection ends on cancellation or access denial and reports write failures. When the picker is unavailable, the app uses an available save method. / 保存先の選択は取消やアクセス拒否で終了し、書き込みに失敗した場合はエラーを表示します。保存ダイアログが使えない環境では利用できる保存方法を使います。
- A saved report opens and exports locally without an API key. DOCX preserves the original report timestamp. / 保存済みレポートの読み込みと再保存は、APIキーなしで行えます。DOCXは元の作成日時を保持します。
- Key setup shows authentication pending. The provider's successful response confirms authentication during the usual workflow. / キー設定後は「設定済み・認証未確認」と表示し、通常の処理で提供元から成功応答を受けると「認証済み」に変わります。
