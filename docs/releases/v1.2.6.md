# Viral Radar v1.2.6

## English

- Added an explicit OpenAI model selector. GPT-6 Astra is shown as the recommended option, and fallback proceeds only to models below the selected model.
- API connection no longer starts retrieval automatically. OpenAI requires a model selection, and both OpenAI and Gemini require the user to press `検索・分析を開始`.
- Unified API connection, model selection, and start confirmation in one AI settings panel.
- Removed the temporary selected/attempted/adopted status boxes because the settings panel closes when analysis starts.
- Added Viral Radar-specific model descriptions while synchronizing only model order and pricing metadata from Nano Banana Pro.
- Updated the deployment lifecycle to use the shared Antigravity release preflight and release-copy transaction.

## 日本語

- OpenAIモデルを明示的に選べるようにしました。GPT-6 Astraを推奨候補として表示し、フォールバックは選択モデルより下位だけへ進みます。
- API接続直後の自動取得を停止しました。OpenAIはモデル選択、OpenAIとGeminiの両方で `検索・分析を開始` を押す必要があります。
- API接続、モデル選択、開始確認を1つのAI設定パネルにまとめました。
- 分析開始時に設定パネルとともに消える「選択・試行・採用」欄を削除しました。
- Nano Banana Proからはモデル順と料金情報だけを同期し、物語バズメーカー専用のモデル説明を追加しました。
- Antigravity共通の事前検査と公開版コピー処理を使うデプロイ経路へ統一しました。
