# v1.4.0 — Combined research for storytelling / 物語づくりのための複合分析

Release date: November 13, 2026. / 公開日: 2026年11月13日。

- Compare public Web context and optional X evidence to create manga, video and novel concepts. Every combined-source concept keeps references and explains the creative transformation. / 公開Webの背景情報と任意のX補助情報を比較し、漫画・動画・小説の企画へ反映。各案に両情報源の参照と、物語への具体的な変換理由を保持します。
- Keep manga as the default; remove X-post drafting and X-only analysis. / 漫画を初期選択に維持し、X向け投稿文カテゴリとX単独分析を削除しました。
- Compact settings and paragraph spacing; show creative plans before collapsible research details. / 上部設定と段落の余白を縮小し、企画を先に表示。取得資料や指標は折りたたみます。
- Enforce the selected RSS time window and exclude missing, future or expired dates. Distinguish feed-entry and X-post timestamps from retrieval time; feed dates do not establish the original article's publication time. / RSS期間指定を実際の絞り込みへ反映し、日付不明・未来・期間外を除外。RSS配信／X投稿日時と取得日時を別表示し、不明な日付を取得時刻で埋めません。RSS日時は元記事の初出日時の証明ではありません。
- Rotate default searches, exclude used sources and provide previous concepts to the AI. Similarity checks reduce repetition but do not guarantee semantic uniqueness. / 再検索で既定の検索語を切り替え、使用済み資料を除外し、過去案をAIへ渡します。近似チェックで反復を抑えますが、あらゆる言い換えの検出を保証するものではありません。
- Preserve API connections across re-search; recognize authentication errors by actual API responses. / 再検索で接続を保持し、文章中の「拒否」「認証」ではなく、実際のAPI認証エラーを判定します。
- Correct false rejection of fictional income choices and align the response format. Invalid content receives one correction on the same model. Each task allows at most three attempts, each limited to four minutes; timeouts do not trigger automatic retries. / 架空人物の収入を扱う企画の誤判定と応答形式の不整合を修正。内容不備は同じモデルで1回修正し、各処理は最大3試行・各4分まで。時間切れは自動再試行しません。
- Preserve references, synthesis and manuscripts in JSON, Markdown and DOCX. Imported reports retain their original search round. / JSON・Markdown・DOCXに根拠、複合分析、本文を保持し、読み込み時も元の検索回数を維持します。
- Stop interpreting character-description fragments as names during manuscript checks. Show the specific rejection reason and keep rejected text in memory for inspection and rechecking without another API call. / 本文検査で人物の説明文の断片を人名と誤認する不具合を修正。不合格理由を具体的に表示し、不採用本文をメモリで保持して、APIを使わず再検査できます。
- X is optional, off by default and available through the local relay only. Tokens stay in memory, excluded from saved files. / Xは任意・初期オフ・ローカル中継専用。トークンはメモリのみで保持し、保存ファイルへ含めません。
