# v1.4.1 — One source, clear X availability / 同じソースとX利用条件の明示

GitHub Pages and local use share one source and version. The public page hides X settings and links to the source ZIP and local setup instructions. When run locally, the same app enables optional X evidence for combined Web + X story planning. / GitHub Pagesとローカルでソース・バージョンを統一。公開WebではX設定を非表示にしてダウンロード・起動手順を案内し、ローカル起動時はXを選択できます。

- Connect the generation AI first, then optionally X below it. Public pages show only a compact local-use guide; no X settings are displayed. / 生成AI→任意のX接続→分析開始の順に配置。デモではX設定パネルを表示せず、ローカル利用案内だけを表示します。
- Each user runs the X connection on their own PC with their own API keys. No shared author server, author credentials, extension or Cloudflare setup. / 利用者自身のPCとAPIキーを使用し、作者の共有中継や認証を使いません。
- Extract the ZIP and run the Windows batch to prepare missing Node.js and dependencies automatically and open the app. The portable runtime stays inside the app folder; no administrator access or system PATH change is needed. / ZIPを展開してバッチを実行すると、不足するNode.jsと必要な部品を自動準備して起動します。実行環境はアプリ内に置き、管理者権限やPC全体の設定変更は不要です。APIキーは本人が画面で入力します。
- The downloaded source can start, build and test without a sibling Nano Banana Pro checkout. Bundled-model checks run locally; strict upstream synchronization remains mandatory in author release preflight. / ダウンロード後の起動・ビルド・検査が別アプリのフォルダーを要求する問題を修正。同梱設定を検査し、作者側の公開前同期検査は維持。
- Public Web + X analysis still produces manga/video/fiction plans and manuscripts. X-post drafting and X-only output are not included. / 複合分析から物語企画と本文を作る既存機能を維持。X投稿文やX単独出力は追加していません。
- An unsubmitted X token is preserved when connecting the AI key or changing other controls. It is not copied into report exports or HTML attributes. / 生成AIの接続などで画面が更新されても、設定前のXトークン入力が消えないよう修正。レポート出力やHTML属性には含めません。

Local candidate; not published yet. Live API verification completed two combined Web + X manga-planning runs, re-search with retained connections, and a 2,773-character manuscript. / ローカル候補・未公開。実APIでWeb＋Xの複合漫画企画を連続2回、接続を保った再検索、2,773字の本文生成を確認しました。
